# 🍔 FoodSpot - App de Pedidos de Comida

Este es un proyecto de ejemplo desarrollado en **Kotlin** usando **Jetpack Compose**. Permite al usuario explorar restaurantes por categoría, buscar platos específicos y gestionar un carrito de compras.

---

## ✨ Funcionalidades principales

- Navegación por categorías de comida (rápida, asiática, saludable).
- Lista dinámica de restaurantes.
- Buscador por nombre de restaurante, categoría o platillo.
- Carrito funcional con opción de vaciarlo.
- Interfaz moderna con `Jetpack Compose` y navegación entre pantallas.

---

## 🛠️ Cómo ejecutar el proyecto

1. Abrí **Android Studio**.
2. Seleccioná **"Open an existing project"** y elegí esta carpeta (`00083723-FoodSpot-By-Agarcia`).
3. Esperá que gradle sincronice.
4. Conectá un emulador o dispositivo.
5. Hacé clic en **Run ▶️** para compilar y lanzar la app.

📦 Mínimo SDK requerido: `API 24` (Android 7.0)
